# LeetCode Solutions in C

This repository contains C implementations and short write-ups for selected LeetCode problems. Each problem includes a `.c` solution file and a matching `.md` explanation with the approach, complexity, and notes.

## Categories

- Arrays & Strings
- Basic Algorithms
- Stacks
- Linked Lists (planned / upcoming)

## Completed Problems

1. Two Sum
2. Reverse a String
3. Valid Anagram
4. Best Time to Buy and Sell Stock
5. Longest Common Prefix
6. Binary Search
7. Move Zeroes
8. Valid Parentheses

## Project Structure

- `arrays-strings/` - array and string problems
- `basic-algorithms/` - algorithmic fundamentals
- `stacks/` - stack-based problems
- `linked-lists/` - linked list work in progress

## Example Compile Command

```bash
gcc arrays-strings/01-two-sum.c -o two-sum
./two-sum
```

Each solution is kept deliberately simple and readable for learning and interview practice.
